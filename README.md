## 🧱 Tech Stack

* ⚡ Vite (build tool & dev server)
* ⚛️ React 19 (JavaScript only)
* 🔀 React Router 7
* 🎨 Tailwind CSS 4
* 🎬 Framer Motion (animations)
* 🎯 Lucide React + React Icons (icon libraries)
* 🔔 React Toastify (notifications)
* 🧠 clsx + tailwind-merge (conditional/merged class handling)
* 🧩 Component-based architecture
* 🎯 Custom reusable UI system

## 🛠️ Installation & Usage

**1. Clone the repo**
```bash
git clone https://github.com/shakilcreativework/creativework.git
cd creativework
```

**2. Install dependencies**
```bash
npm install
```

**3. Run the dev server**
```bash
npm run dev
```
Visit the local URL Vite prints in your terminal (typically `http://localhost:5173`).

**4. Build for production**
```bash
npm run build
```

**5. Preview the production build locally**
```bash
npm run preview
```
